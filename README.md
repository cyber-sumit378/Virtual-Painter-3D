# 🎨 Architect Studio Pro — AI 2D & 360° 3D Virtual Painter

An interactive architectural visualization and virtual wall-painting studio. Upload room or building surface photos, remove unwanted clutter, test realistic paint shades with texture preservation, and preview everything live inside a **360° Interactive 3D Room**.

---

## ✨ Key Features

- **🌗 Split-Screen Studio Workspace:** Edit on the 2D canvas on the left and watch real-time updates inside the 360° 3D room on the right.
- **🧍 360° Inside-Room VR View:** Stand at the center of the room, drag to look around all 4 walls, ceiling, and floor, or switch to an outside Dollhouse view.
- **🪄 Smart Edge-Locked Paint Fill:** Apply custom colors or quick shades while preserving original wall textures, shadows, and architectural borders.
- **🧹 Interactive Object Eraser (Inpainting):** Selectively brush over unwanted furniture or wall clutter to remove it without damaging wall designs.
- **💠 3D Floor Tile Generator:** Generate realistic checkerboard marble and tile layouts for floor surfaces in one click.
- **🖼️ 2D Object & Frame Placement:** Overlay custom PNG/JPG decor, frames, or architectural elements directly onto walls.
- **☀️ Dynamic Lighting Preview:** Toggle between bright Daylight and Warm Night LED lighting simulations.
- **↩️ Multi-Step Undo & High-Res Export:** Full history support and instant client-ready image export.

---

## 🛠️ Tech Stack

- **Frontend / UI:** React, TypeScript, Tailwind CSS, Lucide Icons *(Web Studio)* / PyQt6 *(Desktop)*
- **3D Rendering Engine:** Three.js / WebGL & OpenGL
- **Image Processing:** HTML5 Canvas Pixel Manipulation / OpenCV & NumPy
